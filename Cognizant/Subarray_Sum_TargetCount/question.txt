Problem Statement : Count Valid Subarrays of size 3.

problem Description
You are given an array of integers containing N elements. Your task is to find and return an
integer value representing the total number of subarray of size 3 where the sum of the first
element and the third element is equal to the second element.

A subarray is a continous sequence of elements  in an array.

Example

input 1 : [1,2,1,3,5,2,4,2]
input 2 : 8
output : 3
